# Experimental record and selection criteria

This repository includes only experimental studies that appear in the CIDM manuscript, with their frozen evaluation protocol.

Included: controlled comparison; eight-regime multiphysics benchmark with corrected diffusion–sorption; component attribution for six manuscript-named mechanisms; long rollout with initial-noise robustness; and causal self-reencoding/state-consistency diagnosis.

Excluded: exploratory comparison (preliminary trial); follow-up mechanism-specific interaction/rescue experiments; independent model-capacity scaling and compute-saturation studies. These exclusions are intentional and are not evidence of unreported successful experiments.

The full original notebook bytes, revision names and source package hashes are retained outside the public repository. Public notebook code cells are preserved while notebook execution outputs, machine-specific metadata and log noise are removed. All included numerical results are direct data extracts, not rerun estimates.

The controlled comparison has 180 completed per-seed records. The eight-task benchmark has 120 completed per-seed records after the diffusion–sorption correction. The main component-attribution table contains 90 completed records for six named mechanisms. The long-horizon evaluation has 48 completed model/task/seed combinations. The state-consistency study has 18 completed combinations.
